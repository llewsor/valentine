# Valentine

A tiny React app to ask Marita-Louise to be my valentine, with a playful runaway "No" button and a celebratory "Yes" reveal.

## Features
- Animated "No" button that dodges the cursor while staying inside the button area
- "Yes" button grows when "No" runs away
- Clicking "Yes" shows a YAY message and a celebration GIF
- Mobile-friendly layout

## Tech
- React + Vite

## Local Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy (GitHub Pages)
```bash
npm run deploy
```

## Customize
- Update the name in `src/App.jsx`
- Swap the GIF URL in `src/App.jsx`
